# PSE em Ação

Repositório da **1ª entrega da AEP do 2º semestre de 2026** dos cursos de Engenharia de Software e Análise e Desenvolvimento de Sistemas da Unicesumar.

## Projeto

**PSE em Ação — Sistema de Planejamento e Acompanhamento de Ações de Saúde na Escola**

Tema escolhido para contextualização: **Saúde Mental no ambiente escolar**.

A proposta consiste no planejamento de uma aplicação em linguagem C, executada em terminal, para auxiliar uma equipe escolar e de saúde no cadastro, consulta e acompanhamento de ações coletivas do Programa Saúde na Escola (PSE).

## Objetivo

Desenvolver uma solução introdutória em linguagem C capaz de planejar, registrar e acompanhar ações coletivas do PSE, mantendo as informações organizadas e preservando a privacidade dos estudantes.

## Funcionalidades previstas

- Cadastrar ações do PSE
- Listar ações cadastradas
- Pesquisar ações por código, escola ou tema
- Atualizar a situação das ações
- Registrar a quantidade efetiva de participantes
- Gerar um resumo geral das ações
- Validar entradas importantes do usuário

## Observações éticas

O sistema utilizará somente dados fictícios e informações coletivas. Não serão armazenados nomes, diagnósticos, prontuários ou outros dados sensíveis individuais de estudantes. A aplicação também não realizará diagnóstico, triagem, prescrição ou recomendação de tratamento.
