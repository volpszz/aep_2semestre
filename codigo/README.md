# Código-fonte

Esta pasta será utilizada para a implementação do sistema **PSE em Ação** em linguagem C.

Na 1ª etapa, a implementação completa ainda não é obrigatória. O código será desenvolvido de forma incremental nas próximas sprints.

Funcionalidades previstas:
- cadastro de ações;
- listagem;
- pesquisa;
- atualização de situação;
- registro de participantes;
- geração de resumo geral;
- validação de entradas.
