# Fluxogramas

Esta pasta é destinada aos fluxogramas da AEP.

Devem ser mantidos aqui:
- fluxograma geral do sistema, representando o menu e as principais opções;
- fluxograma detalhado de uma operação escolhida pelo grupo.

No documento da 1ª entrega, o grupo detalhou a operação de **cadastro de ação**.
